## Principes méthodologiques clés

1. **Itération V → V+1** sur 5 prompts stressant les règles distinctives
2. **Tests multi-LLM** pour distinguer défauts du skill vs défauts d'un modèle
3. **Prompts répliques exactes** entre versions pour mesurer le delta
4. **Pas d'auto-déclaration** — le skill s'applique silencieusement
